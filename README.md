#  Personal Introduction Program

A simple, interactive Python script that collects user information and displays a formatted welcome message. This project was built as part of a foundational Python programming activity.

## Features
- **User Input:** Collects name, age, hobby, and favorite coding language.
- **Type Conversion:** Handles age as an integer to ensure data integrity.
- **Advanced Formatting:** Utilizes **f-strings** and **Triple Quotes (`"""`)** for a clean, multi-line terminal display.

## Technical Requirements
- **Python Version:** 3.6 or higher (uses f-strings).
- **IDE:** Visual Studio Code (recommended).

## How to Run
1. Ensure you have Python installed.
2. Download or copy the `personal_intro.py` file to your computer.
3. Open your terminal or command prompt.
4. Navigate to the folder containing the file and run:
   ```bash
   python personal_intro.py
